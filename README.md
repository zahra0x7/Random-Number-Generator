# 🎲 Random Dice Roller

A simple and interactive Dice Roller built using **HTML, CSS, and JavaScript**. Click the Roll button to generate three random numbers between 1 and 6, just like rolling three dice.

## **Live Demo**

[Random Number Generator](https://rndm-num-gen.netlify.app/?utm_source=chatgpt.com)

## ✨ Features
- Generates three random numbers simultaneously.
- Numbers range from 1 to 6.
- Interactive Roll button.
- Hover effects using CSS transitions.
- Random number generation using JavaScript.

## 🛠️ Technologies Used
- **HTML5** – Page structure and elements.
- **CSS3** – Styling, colors, layout, and hover effects.
- **JavaScript** – DOM manipulation, click events, and random number generation.

## 📚 Concepts Practiced
- `document.getElementById()`
- `onclick` event handling
- `Math.random()` and `Math.floor()`
- Variables and `let`
- `textContent` for updating HTML elements

## 🚀 How to Use
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Click the **Roll** button.
4. Enjoy your three random dice numbers!
